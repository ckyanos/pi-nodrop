# 真实模型固定全量实验：累计阈值批次

2026-10-29，在 Linux 6.8 虚拟机中使用真实模型驱动 Pi，执行证书生成、日志汇总和 Git 恢复 3 个 Terminal-Bench 任务。每个任务从全新文件系统运行一次，由模型自主选择工具及参数。

本批保持 NoDrop 采集和调用身份关联，采用 `fixed-raw` 模式旁路工具策略选择，所有调用固定原样保留。

## 结果

| 任务 | 原始任务测试 | 实际 API 请求 | 执行调用数 | 累计 token | 模型及工具会话时间（秒） |
|---|---|---:|---:|---:|---:|
| `openssl-selfsigned-cert` | 6/6 通过 | 9 | 9 | 34418 | 72.81 |
| `log-summary-date-ranges` | 2/2 通过 | 4 | 5 | 31746 | 56.96 |
| `fix-git` | 2/2 通过 | 8 | 13 | 35280 | 36.27 |
| 合计 | 3 个任务通过 | 21 | 27 | 101444 | 166.04 |

三轮均触及累计 30000 token 的预算阈值。运行器在响应结束后检查，因此最后一次响应可使累计量跨过阈值。证书任务记录 `token_limit`；日志和 Git 任务记录 `token_limit` 及会话取消。预算结束时生成的任务文件均通过原始验证器，实验保留测试结果与会话结束原因两个字段。

累计 token 来自 API 响应的 `usage.totalTokens`，含多轮输入、输出及缓存读取：

| 用量字段 | 合计 |
|---|---:|
| 非缓存输入 | 21481 |
| 输出 | 7003 |
| 缓存读取 | 72960 |
| 缓存写入 | 0 |

完整数据见[机器可读结果](live-fixed-raw-results-20261029.json)。

## 采集及请求核对

27 次调用产生 96297 个保留的原始事件，共 7700278 字节，调用元数据为 20385 字节。保存的事件策略均为 `raw`，每条记录均通过调用引用核对到声明的原始工具调用 ID。实际执行过程中记录的自动重试次数为 0。

三个任务的首个 API 请求与此前按工具配置的真实模型运行具有相同的提示词、工具定义和其他请求字段，差异仅为 `max_completion_tokens`：本批为 4096，此前为 16384。

本批累计预算为 30000，此前按工具配置组为 200000。两批的预算分别报告；本批提供固定全量模式下的实际模型执行结果。相同工具调用序列的策略对照见[工具回放实验](control-comparison.md)，此前真实模型审计开关数据见[token 对照实验](token-comparison.md)。

## 配置

- Terminal-Bench 2.1，任务源码、镜像及验证器沿用[固定版本清单](../experiments/terminal-bench.json)。
- Linux `6.8.0-137-generic`，QEMU TCG，4 vCPU、4 GiB；chroot、UID 1000。
- Pi `1.4.0`，Node.js `22.20.0`；`deepseek-v4.1-flash-al`，`openai-completions`，`medium` thinking level。
- 两个常驻执行进程，每进程一个 libuv I/O 线程；NoDrop 每线程 1 MiB 缓冲，PKEY 关闭。
- 固定原样保留，调用身份及子进程继承保持开启。
- 单响应上限 4096 token；每任务累计阈值 30000 token、40 个模型响应、100 次工具请求、900 秒。模型及传输自动重试关闭，每任务运行一次。
- 验证器在 Agent 退出、采集模块卸载后运行。

参数见[本批清单](../experiments/live-fixed-raw.json)。
